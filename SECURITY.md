# Security Policy

## Reporting a vulnerability

Please report security bugs found in the source code of Subscriptions for
WooCommerce (WPSubscription) through the
[Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/subscription).
The Patchstack team will assist you with verification, CVE assignment, and
notify the developers of this plugin.

Please **do not** open a public GitHub issue, pull request or support-forum
thread for a security bug. A public report puts every store running the plugin
at risk before a fix exists.

For WPSubscription Pro, the paid add-on, see our
[security page](https://wpsubscription.co/security/).

## Supported versions

Security fixes are released for the latest version only. Update to the newest
release from WordPress.org before reporting, and tell us which version you
tested.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## What to expect

- Patchstack validates the report and forwards it to us.
- We confirm the issue, ship a fix, and Patchstack checks the patch before
  release.
- The vulnerability is published, with credit to the researcher, after users
  have had time to update.

More detail is on our [security page](https://wpsubscription.co/security/).
